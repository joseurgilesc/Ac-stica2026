# Sesión 23: Interferencia

**📚 Sesión** | *Herramientas: p5.js, DAW, Micrófono/altavoz*

## Contenidos

Interferencia.

Superposición.

Refuerzo y cancelación.

Ondas estacionarias.

Nodos y antinodos.

Relación de fase entre señales.

## Actividades

- Demostración con dos señales sinusoidales iguales.
- Modificación de fase para escuchar refuerzo y cancelación.
- Simulación en p5.js de dos ondas que se desplazan en sentidos opuestos.
- Identificación de nodos y antinodos.
- Actividad práctica con dos altavoces o dos señales dentro de un DAW.
- Análisis de problemas de polaridad y fase en grabación multimicrófono.
- Entrega de capturas y explicación de tres situaciones de interferencia.
