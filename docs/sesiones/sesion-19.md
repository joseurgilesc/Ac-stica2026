# Sesión 19: Reverberación

**📚 Sesión** | *Herramientas: p5.js, Micrófono/altavoz*

## Contenidos

Reverberación.

Decaimiento energético.

Tiempo de reverberación.

RT60, EDT y parámetros relacionados.

Influencia del volumen y la absorción.

## Actividades

- Escucha comparativa de una señal seca y señales con diferentes reverberaciones.
- Visualización de curvas de decaimiento.
- Simulación en p5.js de una caída de nivel desde 0 dB hasta -60 dB.
- Modificación de volumen y absorción para observar cambios en el tiempo de reverberación.
- Grabación de palmadas o impulsos en dos espacios diferentes.
- Estimación básica del tiempo de reverberación utilizando software o análisis visual.
- Entrega de un informe comparativo con gráficos y conclusiones.
